# Gradinator Bot

Gradinator Bot — Telegram-клиент информационной системы Gradinator, предназначенный для быстрого доступа к расписанию Ярославского государственного колледжа градостроительства.

Бот работает поверх **G-API** и предоставляет расписание учебных групп через интерфейс Telegram. Помимо расписания, бот позволяет получить тип текущей недели и использовать справочники преподавателей, учебных предметов и аудиторий.

Проект является отдельным клиентским приложением Gradinator и не содержит собственной бизнес-логики обработки исходных файлов расписания. Получение и обработка данных выполняются на стороне G-API.

## Возможности

На текущем этапе Gradinator Bot включает:

- просмотр актуального расписания учебной группы;
- просмотр расписания на вчера, сегодня и завтра;
- автоматический выбор следующего учебного дня в воскресенье;
- отображение типа недели;
- отображение замен в расписании;
- выбор и смену учебной группы;
- поиск по справочнику преподавателей;
- поиск по справочнику учебных предметов;
- поиск по справочнику аудиторий;
- хранение выбранной группы пользователя;
- обработку ошибок и недоступности G-API.

Выбранная пользователем группа хранится локально в SQLite и не передаётся в Telegram или другие внешние сервисы.

## Архитектура

Gradinator Bot выступает клиентом G-API:

```text
Telegram
    ↓
Gradinator Bot
    ↓
   G-API
    ↓
Schedule data
```

Бот отвечает за пользовательское взаимодействие, обработку Telegram-апдейтов, навигацию и форматирование полученных данных.

G-API отвечает за получение, обработку, хранение и предоставление расписания.

Такое разделение позволяет не дублировать логику работы с расписанием в Telegram-клиенте. При изменении внутреннего устройства G-API бот продолжает работать через его HTTP API, пока сохраняется совместимый контракт.

## Поток получения расписания

Запрос расписания проходит следующим образом:

```text
Пользователь
     ↓
Telegram
     ↓
Handler
     ↓
GApiClient
     ↓
G-API
     ↓
Schedule response
     ↓
DaySchedule
     ↓
Formatter
     ↓
Telegram
```

Бот не обращается к исходным Excel-файлам расписания напрямую.

Полученные от G-API данные преобразуются в модели клиента, после чего форматируются в сообщение Telegram.

## Хранение данных

Для локального хранения используется SQLite.

На текущем этапе бот хранит выбранную пользователем учебную группу:

```text
user_id → group_name
```

Локальная база данных является частью состояния конкретного экземпляра бота и не должна помещаться в репозиторий.

## Установка

Для установки зависимостей:

```bash
pip install -r requirements.txt
```

Создайте файл окружения:

```bash
cp .env.example .env
```

В Windows можно создать `.env` вручную на основе `.env.example`.

Пример конфигурации:

```dotenv
BOT_TOKEN=токен от @BotFather
API_BASE_URL=http://localhost:9090
```

`BOT_TOKEN` — токен Telegram-бота, полученный через `@BotFather`.

`API_BASE_URL` — адрес экземпляра G-API, к которому должен обращаться бот.

## Запуск

После настройки окружения:

```bash
python bot.py
```

После запуска бот начинает получать обновления через Telegram Bot API.

## Особенности

### Telegram API

Бот использует long polling для получения обновлений.

При необходимости сетевой доступ к Telegram может выполняться через локальный SOCKS/HTTP-прокси. Настройка прокси относится к окружению запуска и не является частью API G-API.

### Расписание

Бот получает расписание через G-API и не пытается самостоятельно интерпретировать исходные файлы расписания.

При отображении расписания учитывается текущий тип недели. Если для пары существует замена, бот может отображать изменённую ячейку независимо от стандартного числителя или знаменателя.

### Воскресенье

В воскресенье расписание за текущий день не запрашивается.

Кнопка актуального расписания открывает следующий учебный день — понедельник.

Навигация по расписанию также учитывает отсутствие расписания на воскресенье.

## G-API

Бот использует следующие основные группы эндпоинтов G-API:

```text
/api/groups
/api/groups/departments
/api/groups/find-department
/api/groups/department-names

/api/teachers
/api/subjects
/api/rooms

/api/schedule
/api/schedule/{offset}
/api/schedule/current-weektype
```

Административные эндпоинты G-API также поддерживаются клиентом API:

```text
/api/admin/*
```

Однако на текущем этапе бот их непосредственно не использует.

## Обработка ошибок

Ошибки G-API преобразуются в отдельные исключения клиента:

- `GApiBadRequest` — некорректный запрос;
- `GApiForbidden` — доступ запрещён;
- `GApiNotFound` — данные не найдены;
- `GApiUnavailable` — сервис временно недоступен.

Это позволяет отделить HTTP-ошибки API от логики Telegram-обработчиков.
